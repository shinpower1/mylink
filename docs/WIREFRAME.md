## 3. 반응형 뷰포트 규칙 (Responsive Breakpoints)

- **Mobile Viewport (< 640px)**:
  - 컨테이너 가로폭 100% (패딩 `px-4`)
  - 아바타 크기 `w-28 h-28`
  - 단일 열(Single Column) 흐름으로 모바일 스크롤에 최적화
- **Tablet / Desktop Viewport (≥ 640px)**:
  - 최대 너비 `max-w-xl` (576px) 중앙 고정 배치
  - 아바타 크기 `w-32 h-32`
  - 좌우 여백과 네오브루탈리즘 그림자가 강조되는 단독 카드 형태 유지
